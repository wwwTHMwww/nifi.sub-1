# netishield

سیستم خودکار تولید و مدیریت ساب‌لینک V2Ray

## ویژگی‌ها

- 🔄 **بروزرسانی خودکار** هر ۳۰ دقیقه
- 📡 **دریافت از منابع متعدد** با قابلیت اضافه کردن هر منبعی
- 🧹 **پاکسازی و حذف تکراری** کانفیگ‌ها
- 🎯 **انتخاب تصادفی** بهترین کانفیگ‌ها
- 📦 **خروجی یکپارچه** به صورت sub.txt

## نصب و راه‌اندازی

### ۱. Fork مخزن

روی گیت‌هاب، این مخزن را Fork کنید.

### ۲. تنظیم منابع

منابع خود را در Secrets گیت‌هاب تنظیم کنید:

- Name: `SOURCES`
- Value: `["https://url1", "https://url2"]`

یا در فایل `.env` محلی:

```env
SOURCES='["https://url1", "https://url2"]'
